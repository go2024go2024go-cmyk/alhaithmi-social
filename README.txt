موقع الهيثمي لخدمات السوشيال ميديا

الملفات:
- index.html: الصفحة الرئيسية
- style.css: التصميم المتجاوب
- script.js: رابط واتساب والسنة الحالية

قبل النشر:
1. افتح script.js.
2. غيّر 9677XXXXXXXX إلى رقم واتساب الخاص بك مع رمز الدولة، دون + أو مسافات.
   مثال توضيحي فقط: 9677XXXXXXX
3. راجع أسماء الخدمات والأسعار قبل نشر الموقع.

نشر مجاني باستخدام GitHub Pages:
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الثلاثة إلى جذر المستودع.
3. من Settings > Pages اختر Deploy from a branch ثم main و /(root).
4. انتظر حتى يظهر رابط الموقع.

ملاحظة: الموقع لا يجمع المدفوعات ولا يضمن توثيق الحسابات. خدمات التوثيق تخضع لموافقة المنصة.
